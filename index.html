Learning Path

一条主线，三个方向

先把 C 语言和嵌入式 C 打牢，再根据目标选择实时系统、设备通信或网络。后三册没有严格的先后顺序，可以按项目需要交叉阅读。

STEP 01

打基础

从编译链接、类型与内存开始，把指针、数组、结构体和多文件工程讲透。零基础也能跟。

About

为什么做这套教程

市面上的资料常常停在两端：要么只讲语法，要么直接跳到芯片手册。中间那段“为什么这样写、什么时候会出错、怎么验证”很少有人讲清楚。这套教程试图补上这一段。

五册按 语言 → 硬件 → 系统 → 通信 → 网络 组织。每讲都有学习目标、直观解释、图解或交互演示、可运行示例、易错点与练习；跨册案例沿着同一条主线逐步扩展：先在 C 里处理字符串，再在嵌入式 C 里处理串口字节流，最后在协议册里解析完整数据帧。

教程中的 C 示例在主机上以 C11 编译验证；FreeRTOS、寄存器与总线时序等依赖硬件的部分明确标注了平台前提，没有把未验证的内容说成硬件实测。

  • 零基础读者：从第一行 C 开始，不假设你学过单片机。
  • 本科学生：可配合 C 语言、单片机、操作系统与网络课程使用。
  • 自学者：用课程地图和自测题补齐零散知识。
  • 嵌入式实践者：查寄存器、位操作、队列、协议帧与排错思路。
