3.1IP 地址 = 网络号 + 主机号

IPv4 地址 32 位，写成四段十进制（192.168.1.10）。它由两部分组成：网络号（在哪个网络）和主机号（网络里的哪台设备）。分界线由子网掩码决定。

3.2CIDR：用 /n 表示掩码

/24 表示前 24 位是网络号，等价于 255.255.255.0。常见换算：

前缀掩码地址数可用主机数
/24255.255.255.0256254
/25255.255.255.128128126
/26255.255.255.1926462
/27255.255.255.2243230
/28255.255.255.2401614
/30255.255.255.25242（点对点链路）

主机数 = 2(32-n) - 2，减去网络地址和广播地址。 exceptions：/31 点对点链路（RFC 3021）可用 2 个地址，/32 表示单个主机路由。

动手看

子网计算器

输入 IP 和前缀，实时得到网络号、广播地址、可用范围与主机数，并显示二进制对齐过程。

网络地址 = IP 与掩码按位与；广播地址 = 网络地址 | ~掩码。这两个地址不能分配给主机。

3.3划分子网：为什么要借位

一个 /24 有 254 个可用地址。如果只有 20 台设备，剩下的地址就浪费了，而且所有设备在同一个广播域里。划分子网就是从主机号里借几位当网络号。

子网 1：192.168.1.0/26 可用 .1 – .62 子网 2：192.168.1.64/26 可用 .65 – .126 子网 3：192.168.1.128/26 可用 .129 – .190 子网 4：192.168.1.192/26 可用 .193 – .254
工程习惯

规划地址时按“未来 2–3 年的设备数”留余量。把生产设备、办公设备、访客网络分到不同子网，既方便管理，也方便做访问控制。

3.4默认网关：出网找谁

主机发数据前先判断：目的 IP 和我在同一个子网吗？

  • 是：直接 ARP 找对方 MAC，发给它。
  • 否：发给默认网关（路由器的内网地址），由它继续转发。
ip addr # Linux：地址与掩码 ip route # Linux：默认网关 ipconfig # Windows：地址、掩码、网关 route print # Windows：路由表
易错

“能上局域网、不能上网”最常见的原因是默认网关没配或配错，其次是 DNS 配错。先 ping 网关，再 ping 8.8.8.8，最后 ping 域名，三步就能定位。

  1. 192.168.10.130/26 的网络号、广播地址、可用范围是什么？
  2. 为什么 /24 的可用主机数是 254 而不是 256？
  3. 一台设备 IP 是 192.168.1.10/24，网关是 192.168.2.1，能上网吗？
  4. 169.254.x.x 地址说明什么？
参考答案与思路

1. /26 的块大小是 64，130 落在 128–191 这一段：网络号 192.168.10.128，广播 192.168.10.191，可用 129–190。

2. 网络地址（主机号全 0）和广播地址（全 1）不能分配给主机。

3. 不能。网关不在同一子网，主机无法 ARP 到网关，包发不出去。

4. DHCP 没拿到地址，系统自动配了链路本地地址；通常意味着 DHCP 服务器不可达。

自测：192.168.1.100/25 的网络地址是？

/25 把最后一个字节分成 0–127 和 128–255 两段；100 落在前一段，所以网络地址是 192.168.1.0，广播是 192.168.1.127。

本讲小结

  • IP = 网络号 + 主机号，掩码决定分界。
  • CIDR 用 /n 表示前缀，主机数 = 2^(32-n) - 2。
  • 网络地址与广播地址不能分配给主机。
  • 同子网直接 ARP，跨子网交给默认网关。
  • 私有地址不能直接出现在公网。
