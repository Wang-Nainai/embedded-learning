10.1Wi-Fi 是共享介质

以太网交换机每个端口是独立的冲突域，Wi-Fi 则是一个共享的无线电空间：同一信道上的设备轮流发言，靠 CSMA/CA 避免冲突。所以“信号满格但很慢”很常见——不是信号问题，是大家在排队。

概念含义
SSID网络名字，可以多个 AP 共用一个
BSSID某个 AP 的 MAC 地址
Station（STA）终端设备，如手机、ESP32
AP接入点，提供无线接入
信道2.4 GHz 常用 1/6/11（互不重叠）
RSSI信号强度，约 -30 dBm 很强，-80 dBm 很弱

10.2一次 Wi-Fi 连接经历什么

扫描　主动/被动发现 SSID 与加密方式。
认证与关联　与 AP 建立链路层关系。
四次握手　WPA2/WPA3 派生会话密钥，验证密码。
DHCP　拿到 IP、掩码、网关、DNS。
联网　DNS 解析、TCP 连接、应用协议。
易错

“连上 Wi-Fi”不等于“能上网”。前者是链路层关联成功，后者还需要 DHCP 拿到地址、网关可达、DNS 可用。排障时按这四步逐层确认，不要一上来就重刷固件。

10.3WPA2 与 WPA3

WPA2-PSKWPA3-SAE
认证预共享密钥（PSK）SAE（对等同时认证）
离线字典攻击抓握手包可离线爆破SAE 抵抗离线猜测
前向保密不支持支持
设备兼容性几乎所有设备较老设备可能不支持

企业环境用 802.1X/EAP，每台设备一个凭据，便于审计与吊销；家庭/小项目用 PSK 足够，但密码要足够长。

10.4IPv6：地址多了，玩法也变了

IPv6 地址 128 位，通常写成 8 组十六进制。一个 /64 子网就有 264 个地址，足够给每台设备分一个“公网地址”。

类型前缀说明
全球单播2000::/3公网可路由
链路本地fe80::/10每块网卡自动生成，仅本地链路
唯一本地fc00::/7类似私有地址
回环::1/128本机
组播ff00::/8ND、路由协议

IPv6 通常不需要 NAT，设备用 SLAAC 自动配置地址（基于前缀 + 接口标识），用 ND（邻居发现）替代 ARP。这带来一个安全含义：设备可能直接暴露在公网，防火墙策略必须显式配置。

工程习惯

设备同时支持 IPv4/IPv6 时，优先使用 Happy Eyeballs 思路：并行尝试，谁先通用谁，避免“IPv6 配置了但不通”导致长时间等待。

10.5联网安全：三件事不能省

传输

加密

用 TLS（MQTT 8883、HTTPS 443），不要明文传凭据。校验服务器证书与域名。

身份

认证

每台设备独立凭据，支持吊销；不要所有设备共用一个密码。

固件

完整性

OTA 包要签名，启动时校验；关闭调试口，防止被读出密钥。

错误做法风险正确做法

参考答案与思路

1. 关联是否成功 → 是否拿到 IP（DHCP）→ 网关是否可达 → DNS 是否可解析。

2. SAE 抵抗离线字典攻击，并提供前向保密。

3. 设备可能直接被公网访问，必须配置防火墙/安全组，不能依赖 NAT 当“天然防火墙”。

4. 固件可被提取，一处泄露会导致所有同型号设备失守；应使用每设备独立凭据并支持吊销。

自测：IPv6 中替代 ARP 的机制是？

IPv6 用 ICMPv6 的邻居发现（ND）完成地址解析、重复地址检测与路由器发现；ARP 在 IPv6 中不再使用。

本讲小结

  • Wi-Fi 是共享介质，速率受信道与排队影响。
  • 连接成功不等于能上网，要逐层检查 DHCP/网关/DNS。
  • WPA3 用 SAE 提升抗离线爆破能力。
  • IPv6 地址充足、通常无 NAT，安全策略要显式配置。
  • 加密、认证、固件完整性是联网设备的三条底线。
