11.2错误信息怎么读

现象含义先查
Connection refused对方可达，但端口没监听/被拒绝服务是否启动、端口是否写错、防火墙
Connection timed out包发出去没有回应路由、防火墙丢包、IP 写错、对方没开机
No route to host本地路由表找不到路径网关/掩码配置
Name or service not knownDNS 解析失败DNS 配置、域名拼写
TLS handshake failed证书/协议/时间问题设备时间、根证书、SNI
Connection reset对方或中间设备发了 RST服务崩溃、防火墙、超时回收

11.3抓包：看到真相

当 ping 通、端口也通，但应用就是不对，就该抓包了。Wireshark 能解码 TCP 流、HTTP、MQTT，直接看到“发了什么、回了什么”。

sudo tcpdump -i any -n port 1883 -w mqtt.pcap sudo tcpdump -i any -n host 192.168.1.50 and port 80
工程习惯

抓包要在两端同时抓（设备侧 + 服务器侧），才能区分“没发出去”“发出去了没收到”“收到了没处理”。只抓一端，很容易得出错误结论。

11.5综合项目：设备遥测上报

目标：设备通过 Wi-Fi 联网，周期采集数据，经 MQTT 上报；同时订阅控制主题，收到指令后执行并回复状态。全部可以在本机 + 局域网验证，不需要公网服务器。

模块职责失败时
Wi-Fi 管理连接、断线重连、信号监测指数退避重连，状态上报
MQTT 客户端连接 Broker、发布、订阅、心跳重连后重新订阅，补发离线数据
采集周期读取传感器读数非法时丢弃并计数
命令处理解析控制指令、执行、回复非法指令回复错误码
看门狗监控任务健康关键任务卡死则复位
[设备/模拟器] ──Wi-Fi/本机──> [Mosquitto Broker 192.168.1.x:1883] │ ├──> [订阅者 mosquitto_sub] └──> [控制发布 mosquitto_pub] # 安装 mosquitto 后，本机启动 mosquitto -p 1883 -v # 另开终端：订阅所有设备遥测 mosquitto_sub -h 127.0.0.1 -t 'device/+/telemetry' -v # 发布一条控制指令 mosquitto_pub -h 127.0.0.1 -t 'device/esp32-001/cmd' -m '{"led":1}'
实现细节

如果没有真实设备，可以用 Python 的 paho-mqtt 或 Node 的 mqtt 包写一个模拟器，行为与设备一致：连接、发布、订阅、断线重连。这样协议与后端逻辑可以先在电脑上验证，再移植到固件。

11.6验收标准

  • 设备上电后 10 秒内连上 Wi-Fi 与 Broker
  • 每 5 秒上报一次，断网后本地缓存，恢复后补发（或明确丢弃策略）
  • 收到控制指令后 1 秒内执行并回复
  • Broker 重启后设备能自动重连并重新订阅
  • 连续运行 24 小时，内存/连接数不持续增长
  • 抓包能看到完整的 CONNECT/SUBSCRIBE/PUBLISH 流程
项目练习 · 第 11 讲
  1. 用 curl -v 访问一个不存在的端口，观察错误信息。
  2. 用 tracert 看一次外网路径，指出第一跳是谁。
  3. 设计断线重连策略：初始 1 秒，最大 60 秒，指数退避 + 抖动。
  4. 如果设备时间不可用，HTTPS 证书校验会怎样？如何兜底？
参考答案与思路

1. 通常是 Connection refused，说明 IP 可达但端口没有监听。

2. 第一跳通常是家里的路由器/网关；后续是运营商网关。

3. delay = min(60, 2^n)，再加 0–1 秒随机抖动，避免所有设备同时重连造成风暴。

4. 证书有效期校验会失败（“not yet valid”）。兜底：首次联网用 NTP 校时；或使用较长有效期的证书 + 构建时间下限；不能直接关闭校验。

自测：Connection refused 通常说明？

收到 RST 才会“refused”，说明包到了对方、对方明确拒绝；完全不通通常是 timeout，DNS 失败则是名字解析错误。

本讲小结

  • ping/traceroute/netstat/curl/dig 能覆盖大部分排查。
  • 错误信息要分清 refused、timeout、DNS、TLS。
  • 抓包要两端同时抓，才能定位“哪一段丢了”。
  • 排查按链路 → 网络 → 传输 → 应用逐层进行。
  • 项目可在本机 + 局域网完整验证，不需要公网服务器。
