A.1常用 API 速查

API上下文阻塞说明
xTaskCreate任务/调度前否栈深度单位是字
vTaskDelete任务否删除自己传 NULL
vTaskDelay任务是单位 tick
vTaskDelayUntil任务是固定周期，不累积漂移
xTaskGetTickCount任务/ISR否ISR 用 xTaskGetTickCountFromISR
xQueueCreate任务/调度前否长度 × 元素大小
xQueueSend / Receive任务是带 tick 超时
xQueueSendFromISRISR否带 pxHigherPriorityTaskWoken
xSemaphoreCreateBinary任务/调度前否初值 0
xSemaphoreCreateCounting任务/调度前否最大计数、初值
xSemaphoreCreateMutex任务/调度前否有所有者、优先级继承
xSemaphoreTake / Give任务Take 可阻塞Give 不阻塞
xSemaphoreGiveFromISRISR否互斥量不能用
xEventGroupWaitBits任务是AND/OR 等待
xEventGroupSetBits任务否ISR 用 FromISR
ulTaskNotifyTake任务是计数式通知
xTaskNotifyWait任务是取值式通知
vTaskNotifyGiveFromISRISR否最常用的 ISR→任务唤醒
xTimerCreate任务/调度前否周期 + 自动重载
xTimerStart / Stop任务可短等通过命令队列
taskENTER_CRITICAL任务否屏蔽受管中断
vTaskSuspendAll任务否只禁止任务切换

现象优先排查验证手段

A.4术语表

TCB任务控制块，保存任务状态、栈指针、优先级等。
tick内核时基单位，由 SysTick 或外设定时器产生。
抢占更高优先级任务就绪时立刻夺走 CPU。
时间片同优先级任务按 tick 轮流运行。
阻塞任务主动等待事件/超时，不占 CPU。
挂起任务被显式暂停，无超时，必须恢复。
优先级反转高优先级任务被中优先级任务间接阻塞。
优先级继承持锁者临时提升到等待者的优先级。
高水位任务栈历史最小剩余量。
碎片空闲内存总量够，但没有足够大的连续块。
守护任务软件定时器的回调执行者。
临界区屏蔽中断/调度的代码段，保证原子性。

A.5上线前检查清单

  • 每个任务都有阻塞点，没有纯忙等
  • 所有 xTaskCreate / 队列创建都检查了返回值
  • 栈高水位在最坏路径上测过，余量 ≥ 25%
  • 堆最小值稳定，没有持续下降
  • 中断里只用 FromISR API，优先级配置正确
  • 临界区都短，且没有阻塞调用
  • 互斥量加锁顺序统一，关键加锁带超时
  • 看门狗由“全部关键任务健康”驱动
  • 开 configASSERT 跑过完整测试
  • 断链、掉电、错误注入都验证过
