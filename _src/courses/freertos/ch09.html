9.1中断里能调用哪些 API

FreeRTOS 的 API 分成两套：任务上下文用的，和中断上下文用的（后缀 FromISR）。在中断里调用任务版 API，轻则返回错误，重则破坏内核数据结构。

任务上下文中断上下文说明
xQueueSendxQueueSendFromISRISR 版本不能阻塞
xSemaphoreGivexSemaphoreGiveFromISR互斥量没有 FromISR 版本
xEventGroupSetBitsxEventGroupSetBitsFromISR实际是发给定时器守护任务
xTaskNotifyGivevTaskNotifyGiveFromISR常用且高效
vTaskDelay无中断不能延时/阻塞

9.2pxHigherPriorityTaskWoken 与 yield

static void UART_IRQHandler(void) { BaseType_t woken = pdFALSE; /* 必须先初始化为 pdFALSE */ uint8_t byte = uart_read(); xQueueSendFromISR(g_rx_q, &byte, &woken); /* 如果刚才的发送唤醒了更高优先级任务，退出中断时立刻切换 */ portYIELD_FROM_ISR(woken); }

为什么需要这个参数？中断结束时，硬件会恢复被中断的任务。如果刚才的操作让一个更高优先级任务就绪，内核需要“改主意”，在中断退出时切换到它。这个参数就是告诉移植层“要不要切”。

易错

忘记初始化 woken = pdFALSE，或者多个 FromISR 调用共用一个变量却在中途重置，都会导致“该切换时没切换”，表现为高优先级任务延迟运行，甚至偶尔卡死。

9.3Cortex-M 的中断优先级陷阱

FreeRTOS 在 Cortex-M 上要求：调用 FreeRTOS API 的中断，其硬件优先级数值必须 ≥ configMAX_SYSCALL_INTERRUPT_PRIORITY（数值越大，优先级越低）。

/* 典型配置：优先级 5–15 允许调用 FreeRTOS API，0–4 留给极高优先级中断 */ #define configPRIO_BITS 4 #define configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY 5 #define configMAX_SYSCALL_INTERRUPT_PRIORITY (configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY << (8 - configPRIO_BITS)) #define configKERNEL_INTERRUPT_PRIORITY (15 << (8 - configPRIO_BITS))
中断优先级（数值）能否调用 FreeRTOS API典型用途
0–4（最高）不能电机急停、故障保护，必须立刻响应
5–14可以串口、SPI、定时器，使用 FromISR API
15（最低）可以PendSV / SysTick（内核占用）
实现细节

还有两个常见坑：NVIC 的优先级分组必须设置为“全部位用于抢占优先级”（Cortex-M 上通常 NVIC_SetPriorityGrouping(0)）；并且中断优先级要在 NVIC_EnableIRQ 之前设置。否则 FreeRTOS 的临界区无法正确屏蔽中断。

9.4延迟中断处理：ISR 只做最少的事

/* 中断：读硬件、清标志、发通知，立刻返回 */ void ADC_IRQHandler(void) { BaseType_t woken = pdFALSE; uint16_t raw = adc_read_result(); xQueueSendFromISR(g_adc_q, &raw, &woken); portYIELD_FROM_ISR(woken); } /* 任务：做滤波、换算、上报（这些都可能耗时） */ static void adc_task(void *arg) { (void)arg; uint16_t raw; for (;;) { if (xQueueReceive(g_adc_q, &raw, portMAX_DELAY) == pdPASS) { float v = raw_to_voltage(raw); filter_update(v); } } }

9.5中断嵌套与临界区

如果允许中断嵌套，高优先级中断可以打断低优先级 ISR。这时共享数据的保护更复杂：低优先级 ISR 持有的数据，可能被高优先级 ISR 修改。

实践建议：尽量不嵌套，或者只让“绝对不能延迟”的故障中断拥有高于 configMAX_SYSCALL_INTERRUPT_PRIORITY 的优先级，并且这类中断不碰任何共享数据。
