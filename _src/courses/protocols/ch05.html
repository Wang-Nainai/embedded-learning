5.1四根线，全双工

SPI 用四根线：SCLK（时钟）、MOSI（主机→从机）、MISO（从机→主机）、CS（片选，低有效）。主机每发一个时钟，同时移出一位、移入一位，所以是全双工。

特性SPI对比 I²C
线数4（每多一个从机多一根 CS）2
寻址片选，没有地址7 位地址
应答没有 ACK每字节 ACK
速率几 MHz 到几十 MHz100 kHz – 几 MHz
多主机通常单主机支持多主机仲裁

5.2CPOL 与 CPHA：四个模式

模式CPOLCPHA空闲时钟采样边沿
000低第一个边沿（上升）
101低第二个边沿（下降）
210高第一个边沿（下降）
311高第二个边沿（上升）

记忆方法：CPOL 决定空闲电平，CPHA 决定“第几个边沿采样”。CPHA=0 在第一个边沿采样（数据必须在第一个边沿之前就准备好）；CPHA=1 在第二个边沿采样（第一个边沿移出数据）。

动手看

模式选择与波形

切换 CPOL/CPHA，观察空闲电平、数据变化边沿和采样边沿如何变化。数据固定为 0xA5（1010 0101），MSB 先发。

“数据移一位”通常就是模式选错：采样边沿落在了数据变化的同一个边沿上。

5.3片选与时序

#include /* 全双工：发一个字节的同时收一个字节 */ uint8_t spi_xfer(uint8_t out) { uint8_t in = 0; for (int i = 7; i >= 0; i--) { /* MSB 先发 */ gpio_mosi((out >> i) & 1u); gpio_sclk(1); /* 模式 0：上升沿采样 */ in = (uint8_t)((in << 1) | gpio_miso()); gpio_sclk(0); } return in; } /* 一次完整事务：拉低 CS → 传输 → 拉高 CS */ void flash_read_id(uint8_t id[3]) { gpio_cs(0); (void)spi_xfer(0x9F); /* 读 ID 命令 */ id[0] = spi_xfer(0xFF); id[1] = spi_xfer(0xFF); id[2] = spi_xfer(0xFF); gpio_cs(1); }
易错

读回全是 0xFF，通常不是“时钟没起来”，而是 MISO 没人驱动：CS 没拉低、从机没供电、引脚复用没配置成 AF。上拉电阻会把悬空的 MISO 拉成高电平，于是读回全 1。

5.4多从机怎么接

独立片选

最常见

所有从机共用 SCLK/MOSI/MISO，每个从机一根独立 CS。主机同一时刻只拉低一个 CS。

菊花链

省引脚

从机的 MISO 接下一个的 MOSI，共用一根 CS。数据要移过整条链，适合移位寄存器/部分 LED 驱动。

独立片选要注意：不要同时拉低两个 CS，否则两个从机同时驱动 MISO，会打架。上电默认要把所有 CS 拉高。

5.5SPI 没有 ACK，怎么保证可靠

SPI 只保证“时钟和数据按模式移位”，不保证从机收到了、也不保证数据对。可靠性要靠：

  • 从机的状态寄存器（读回配置、检查 busy 位）。
  • 命令回读（写完后读回比较）。
  • 应用层 CRC / 重试。
  • 关键操作加超时，避免死等 busy。

参考答案与思路

1. 空闲高（CPOL=1），第二个边沿（上升沿）采样。

2. CPHA=1 规定“第一个边沿移出数据、第二个边沿采样”，所以数据在第一个边沿变化，给采样留出半个周期。

3. CS 没拉低/接错；从机没供电或复位；MISO 引脚复用/方向配置错误。

4. 每个从机独立 CS，软件保证同一时刻只拉低一个；未选中的从机 MISO 应高阻。

自测：SPI Mode 0 的采样边沿是？

Mode 0：CPOL=0（空闲低）、CPHA=0（第一个边沿采样），所以是上升沿采样。

本讲小结

  • SPI 四线全双工，靠片选选中从机，没有地址和 ACK。
  • CPOL 决定空闲电平，CPHA 决定第几个边沿采样。
  • 模式选错的典型现象是“数据整体移一位”。
  • 读回全 0xFF 先查 CS、供电和 MISO 配置。
  • 可靠性靠状态回读、CRC 和重试，不靠 SPI 本身。
