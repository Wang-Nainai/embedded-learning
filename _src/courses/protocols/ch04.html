4.1两根线，怎么挂一堆设备

I²C 只用两根线：SCL（时钟）和 SDA（数据）。所有设备都把它们接成开漏输出，外加上拉电阻。任何设备只能把线拉低，不能主动拉高——高电平由上拉电阻恢复。

实现细节

开漏 + 上拉构成“线与”：只要有一个设备拉低，总线就是低；所有设备都释放，总线才是高。这让多个设备可以共享总线而不短路，也实现了 ACK 和仲裁。

4.2一次完整的读操作

START　主机拉低 SDA（SCL 高）。
发送地址 + 读位　7 位地址左移一位，最低位 1 表示读。
等待 ACK　从机拉低 SDA 表示“我在”。
接收数据　从机发 8 位，主机回 ACK（还要继续读）或 NACK（读完了）。
STOP　主机在 SCL 高时释放 SDA（上升沿）。
#include #include /* 读寄存器：典型传感器操作 */ bool i2c_read_reg(uint8_t addr7, uint8_t reg, uint8_t *out) { uint8_t a8 = (uint8_t)(addr7 << 1); /* 写 */ if (!i2c_start()) return false; if (!i2c_write(a8)) { i2c_stop(); return false; } /* 地址 NACK */ if (!i2c_write(reg)) { i2c_stop(); return false; } /* 寄存器号 NACK */ /* 重复起始：不发 STOP，直接换方向 */ if (!i2c_start()) return false; if (!i2c_write((uint8_t)(a8 | 1u))) { i2c_stop(); return false; } *out = i2c_read_nack(); /* 只读 1 字节：回 NACK */ i2c_stop(); return true; }
易错

读最后一个字节时必须回 NACK，告诉从机“不要再发了”。如果回 ACK，从机会继续输出，主机却已经发 STOP，时序就乱了。很多“读出来总是多一字节/错位”的问题都出在这里。

4.3NACK、BUSY 与总线锁死

现象原因处理
地址阶段 NACK设备不存在、地址错、供电未就绪扫描地址、检查上拉、延时等待上电
数据阶段 NACK寄存器非法、设备忙、写保护查手册、加延时、检查 WP 引脚
BUSY 一直为 1从机复位时把 SDA 拉低，总线卡死手动发 9 个 SCL 时钟 + STOP 复位总线
偶发错位时钟拉伸未处理、上拉太弱、干扰降低速率、减小上拉、缩短走线
/* 总线恢复：从机可能卡在“等第 9 个时钟”，手动补时钟让它释放 SDA */ void i2c_bus_recover(void) { gpio_set_scl_input(); /* 先释放 SCL */ for (int i = 0; i < 9; i++) { gpio_scl_low(); delay_us(5); gpio_scl_high(); delay_us(5); } /* 手动产生 STOP：SCL 高时 SDA 由低变高 */ gpio_sda_low(); delay_us(5); gpio_scl_high(); delay_us(5); gpio_sda_high(); delay_us(5); }

4.4上拉电阻怎么选

上拉太小：功耗高、低电平灌电流大；上拉太大：上升沿变慢，高速时来不及拉高。经验起点：100 kHz 用 4.7 kΩ，400 kHz 用 2.2 kΩ，具体要按总线电容和器件规格计算。

工程习惯

示波器看 I²C 波形时，重点看上升沿是否“圆角”、高电平是否达到 Vih。上升沿太慢是“偶发 NACK/错位”的常见原因，尤其在长排线、多设备、高电容的板子上。

参考答案与思路

1. 写：0x90（0x48<<1），读：0x91。

2. SCL 高时 SDA 的变化会被解释为 START/STOP；只有在 SCL 低时改变，才是“数据”。

3. 告诉从机停止输出，主机才能安全地发 STOP；否则从机继续驱动 SDA，可能造成总线冲突。

4. 释放 SCL/SDA 为输入，手动输出 9 个 SCL 脉冲，再产生一个 STOP；之后重新初始化 I²C 外设。

自测：I²C 的 START 条件是什么？

START 是“SCL 高时 SDA 下降”，STOP 是“SCL 高时 SDA 上升”。这两个条件与普通数据变化（只能在 SCL 低时发生）区分开。

本讲小结

  • I²C 用开漏 + 上拉实现线与，两根线共享总线。
  • START/STOP 由 SCL 高时 SDA 的跳变定义。
  • 地址 7 位 + R/W，每字节后第 9 个时钟是 ACK/NACK。
  • 读最后一字节回 NACK；从机可时钟拉伸。
  • BUSY 卡死可用 9 个时钟 + STOP 恢复。
