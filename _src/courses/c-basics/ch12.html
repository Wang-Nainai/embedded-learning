12.1递归：把大问题交给同类的小问题

递归函数就是“调用自己”的函数。写对它只需要三件事：

终止条件　最小规模的问题直接给出答案，不再递归。没有它就会无限调用，直到栈溢出。
规模递减　每次递归都必须让问题更小，并且最终能到达终止条件。
结果组合　假设子问题已经算对，想清楚怎么用它拼出当前答案。
#include long long factorial(int n) { if (n < 0) { return -1; /* 非法输入 */ } if (n <= 1) { return 1; /* 终止条件 */ } return (long long)n * factorial(n - 1); /* 规模递减 */ } int main(void) { for (int i = 0; i <= 10; i++) { printf("%d! = %lld\n", i, factorial(i)); } return 0; } 0! = 1 1! = 1 2! = 2 3! = 6 4! = 24 5! = 120 6! = 720 7! = 5040 8! = 40320 9! = 362880 10! = 3628800

递归的执行过程就是不断压栈：factorial(4) 调用 factorial(3)，再调用 factorial(2)……直到 factorial(1) 返回，然后逐层乘回去。每一层都有自己的 n，互不干扰。

12.2递归不一定快：斐波那契的教训

#include /* 直观但低效：同一子问题被重复计算无数次 */ long long fib_naive(int n) { if (n <= 1) return n; return fib_naive(n - 1) + fib_naive(n - 2); } /* 迭代版本：O(n) 时间，O(1) 空间 */ long long fib_iter(int n) { long long a = 0, b = 1; for (int i = 0; i < n; i++) { long long t = a + b; a = b; b = t; } return a; } int main(void) { printf("%lld %lld\n", fib_naive(20), fib_iter(20)); return 0; } 6765 6765

fib_naive(40) 大约要做 3.3 亿次调用，而 fib_iter(40) 只要 40 次循环。递归写法更接近数学定义，但不代表更高效。需要递归又要避免重复计算时，可以加记忆化（把算过的结果存起来）。

12.3递归的经典场景

#include void hanoi(int n, char from, char to, char via) { if (n == 0) return; hanoi(n - 1, from, via, to); printf("%c -> %c\n", from, to); hanoi(n - 1, via, to, from); } int main(void) { hanoi(3, 'A', 'C', 'B'); /* 7 步 */ return 0; } A -> C A -> B C -> B A -> C B -> A B -> C A -> C

汉诺塔的递归结构非常清晰：先把上面 n-1 个从 A 移到 B，把最大的从 A 移到 C，再把 n-1 个从 B 移到 C。总步数是 2n-1，n=64 时约 1.8×1019 步——递归写法正确，但问题本身不可完成。

12.4栈深度：递归的硬限制

每层递归都占一个栈帧。栈空间通常只有几 MB（Windows 默认 1 MB，Linux 常见 8 MB），递归太深就会栈溢出，表现为程序直接崩溃，且往往没有有用的错误信息。

#include int depth(int n) { volatile char padding[1024]; /* 每层占 1 KB；volatile 防止优化删掉栈帧 */ padding[0] = (char)n; if (n == 0) return 0; return depth(n - 1) + 1; } int main(void) { printf("%d\n", depth(100000)); /* 大概率栈溢出 */ return 0; }
工程习惯

处理不确定深度的数据（如解析用户输入、遍历长链表）时，优先用迭代 + 显式栈，而不是递归。真要用递归，先估算最大深度，并给深度加一个上限保护。

12.5链表：用指针把分散的节点串起来

数组要求元素连续存放，插入和删除要搬移大量数据。链表让每个节点单独 malloc，用指针指向下一个节点——插入和删除只需要改几个指针。

#include #include typedef struct Node { int value; struct Node *next; } Node; /* 头插：新节点成为新的头，O(1) */ Node *push_front(Node *head, int value) { Node *n = malloc(sizeof *n); if (n == NULL) { return head; /* 分配失败：保持原链表不变 */ } n->value = value; n->next = head; return n; } /* 遍历：用临时指针，不要移动 head 本身 */ void print_list(const Node *head) { for (const Node *p = head; p != NULL; p = p->next) { printf("%d ", p->value); } printf("\n"); } /* 释放整条链表：必须先保存 next 再 free 当前节点 */ void free_list(Node *head) { while (head != NULL) { Node *next = head->next; free(head); head = next; } } int main(void) { Node *head = NULL; for (int i = 1; i <= 5; i++) { head = push_front(head, i * 10); } print_list(head); /* 50 40 30 20 10 */ free_list(head); return 0; } 50 40 30 20 10

插入与删除，到底改了哪根指针

12.6插入与删除的完整写法

/* 在值为 target 的节点后插入：需要先找到它 */ int insert_after(Node *head, int target, int value) { Node *p = head; while (p != NULL && p->value != target) { p = p->next; } if (p == NULL) { return -1; /* 没找到 */ } Node *n = malloc(sizeof *n); if (n == NULL) { return -1; } n->value = value; n->next = p->next; /* 先接后 */ p->next = n; /* 再接前 */ return 0; } /* 删除第一个值为 target 的节点：需要前驱指针 */ Node *remove_value(Node *head, int target) { Node **link = &head; /* 指向“指向当前节点的指针” */ while (*link != NULL) { Node *cur = *link; if (cur->value == target) { *link = cur->next; /* 让前驱（或 head）跳过它 */ free(cur); return head; } link = &cur->next; } return head; }
工程习惯

Node **link 这种“二级指针”写法能统一处理“删除头节点”和“删除中间节点”，避免为头节点写一份特判。第一次看可能别扭，但在链表、树、哈希表里非常常用。

参考答案与思路

1. 递归：if (n <= 0) return 0; return n + sum(n - 1);。迭代用一个累加变量即可。两者时间复杂度相同，但递归有栈开销。

2. 遍历计数，注意参数是 const Node *，只读不改。

3. 维护 prev = NULL、cur = head；每轮先存 next = cur->next，再 cur->next = prev，然后 prev = cur; cur = next；最后返回 prev。

4. 调用次数约 4.07×1010（约 407 亿次）。即使每次调用只要 1 纳秒，也要约 41 秒；如果每次 100 纳秒，就超过 1 小时。递归深度只有 50，不会栈溢出，纯粹是时间爆炸。

自测：释放链表时，为什么必须先保存 next？

free(p) 之后 p 指向的内存已经归还给堆管理器，再读 p->next 是释放后使用（未定义行为）。所以要在 free 之前把 next 存到局部变量里。

本讲小结

  • 递归三要素：终止条件、规模递减、结果组合。
  • 递归深度受栈大小限制；朴素递归可能带来指数级重复计算。
  • 链表节点独立分配，靠 next 串联，头指针代表整条链。
  • 插入先接后、再接前；删除要先找前驱，free 前先存 next。
  • 有 create 就要有 destroy，所有权要成对设计。
