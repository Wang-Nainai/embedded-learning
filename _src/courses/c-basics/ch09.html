9.1当数据开始“成群出现”

描述一个学生，需要学号、姓名、成绩。用三个独立变量也能写，但一旦有 50 个学生，就会变成 id1, id2, ... 的灾难。结构体把逻辑上属于同一个对象的多个字段打包成一个类型，让“一个学生”成为可以整体赋值、传参、放进数组的单位。

#include #include struct Student { int id; char name[20]; double score; }; int main(void) { /* 按成员顺序初始化 */ struct Student s1 = {1001, "Ada", 92.5}; /* 指定初始化器（C99）：更清晰，顺序无关 */ struct Student s2 = {.score = 88.0, .id = 1002, .name = "Bob"}; printf("%d %s %.1f\n", s1.id, s1.name, s1.score); printf("%d %s %.1f\n", s2.id, s2.name, s2.score); /* 结构体可以整体赋值：逐成员复制 */ struct Student s3 = s1; s3.score = 100.0; /* 修改 s3 不影响 s1 */ printf("%.1f %.1f\n", s1.score, s3.score); return 0; } 1001 Ada 92.5 1002 Bob 88.0 92.5 100.0
易错

结构体不能直接用 == 比较，编译器不会逐成员比较；s1 == s2 直接编译错误。需要自己写比较函数，或者用 memcmp（但填充字节的内容不确定，memcmp 也可能误判，尤其是含指针或浮点时）。

9.2指针、-> 与传参代价

#include struct Student { int id; char name[20]; double score; }; /* 传值：复制整个结构体（这里 32 字节） */ void print_by_value(struct Student s) { printf("%d %s\n", s.id, s.name); } /* 传地址：只复制一个指针，且能修改原对象 */ void bump_score(struct Student *s, double delta) { s->score += delta; /* s->score 等价于 (*s).score */ } int main(void) { struct Student s = {1001, "Ada", 90.0}; print_by_value(s); bump_score(&s, 5.0); printf("%.1f\n", s.score); return 0; } 1001 Ada 95.0
工程习惯

只读的大结构体用 const struct Student *，既避免复制又表明不修改；需要修改时传 struct Student *。只有当结构体很小（比如两个 int）时，传值才更简单。

9.3嵌套、数组与“对象集合”

#include struct Date { int year, month, day; }; struct Employee { int id; char name[24]; struct Date hired; /* 嵌套结构体 */ double salary; }; int main(void) { struct Employee team[2] = { {1, "Alice", {2020, 3, 15}, 12000.0}, {2, "Bob", {2023, 7, 1}, 9800.0} }; double total = 0.0; for (int i = 0; i < 2; i++) { printf("%s 入职 %d-%02d-%02d\n", team[i].name, team[i].hired.year, team[i].hired.month, team[i].hired.day); total += team[i].salary; } printf("平均薪资 %.2f\n", total / 2); return 0; } Alice 入职 2020-03-15 Bob 入职 2023-07-01 平均薪资 10900.00

结构体数组在内存里是连续存放的：每个元素占 sizeof(struct Employee) 字节，元素内部可能因为对齐而插入填充字节。第 2 册会专门讲清楚填充规则，这里只需要知道“结构体的大小不一定等于成员大小之和”。

9.4枚举：给整数起名字

#include enum Color { RED, GREEN = 5, BLUE }; /* RED=0, GREEN=5, BLUE=6 */ enum State { STATE_IDLE, STATE_RUN, STATE_ERROR }; int main(void) { enum Color c = BLUE; printf("%d %d %d\n", RED, GREEN, BLUE); printf("c = %d\n", (int)c); printf("sizeof(enum Color) = %zu\n", sizeof(enum Color)); /* 通常是 4 */ enum State s = STATE_IDLE; switch (s) { case STATE_IDLE: printf("idle\n"); break; case STATE_RUN: printf("run\n"); break; case STATE_ERROR: printf("error\n"); break; } return 0; } 0 5 6 c = 6 sizeof(enum Color) = 4 idle

枚举的本质是有名字的 int 常量，不是“只能取这几个值”的强类型。C 不会阻止你把 99 赋给 enum Color，编译器可能只给一个警告。它的价值在于可读性和调试时能看到名字。

工程习惯

枚举常量名建议带前缀（STATE_IDLE 而不是 IDLE），避免和别的模块重名。C 的枚举常量是全局作用域的，这一点和 C++ 不同。

9.5联合体：所有成员共用一块内存

union 的所有成员从同一个地址开始，大小等于最大的成员。任一时刻只有一个成员的值是有效的（写了 A 再读 B 得到的是 A 的字节按 B 解释的结果）。

#include #include union Value { uint32_t u32; uint8_t bytes[4]; float f; }; int main(void) { union Value v; v.u32 = 0x12345678u; printf("sizeof = %zu\n", sizeof(union Value)); /* 4 */ for (int i = 0; i < 4; i++) { printf("%02X ", v.bytes[i]); } printf("\n"); return 0; } sizeof = 4 78 56 34 12
标准怎么说

“写一个成员、读另一个成员”叫类型双关（type punning）。C 标准允许读取 union 中与最后写入成员“共同的初始序列”，但把 uint32_t 写完再读 float 严格来说不属于这种情况，结果依赖实现。想按位查看浮点数，应使用 memcpy 到 uint32_t，这是标准明确允许的。

#include #include uint32_t float_bits(float f) { uint32_t u; memcpy(&u, &f, sizeof u); /* 标准允许：按字节复制 */ return u; }

9.6typedef：给类型起个短名字

typedef unsigned int u32; typedef struct Student Student; /* 之后可以写 Student s; */ struct Student { int id; char name[20]; }; /* 函数指针类型：这是 typedef 最有价值的地方 */ typedef int (*binop)(int, int); int add(int a, int b) { return a + b; } int main(void) { Student s = {1, "Ada"}; binop op = add; return op(s.id, 2) == 3 ? 0 : 1; }
工程习惯

常见写法是 typedef struct Student { ... } Student;，这样 C 和 C++ 里都能直接写 Student。但注意：typedef 只是别名，不产生新类型，编译器不会帮你区分“学号”和“年龄”这两个都用 int 表示的东西。

参考答案与思路

1. dx = a.x - b.x; dy = a.y - b.y; return sqrt(dx*dx + dy*dy);，记得 #include <math.h> 并链接 -lm（部分平台需要）。

2. 排序时交换整个结构体即可（struct Student t = a[i]; a[i] = a[j]; a[j] = t;），结构体赋值是逐成员复制。

3. 用 switch 或字符串数组，注意枚举值从 0 开始连续时可以直接当下标。

4. 大小等于最大成员的大小（再按最大对齐要求补齐）。成员共用同一段字节，后写的会覆盖先写的，所以同一时刻只有一个成员有效。

自测：struct S { char c; int i; }; 在常见 32 位对齐平台上 sizeof(struct S) 通常是？

char 占 1 字节，后面要插入 3 字节填充，才能让 int 落在 4 的倍数地址上；总大小 8。具体规则（对齐、填充、末尾补齐）在第 2 册第 6 讲展开。

本讲小结

  • 结构体把相关字段打包成一个类型，可以整体赋值和传参。
  • 结构体不能直接用 == 比较；传大结构体优先传 const 指针。
  • s->x 就是 (*s).x 的简写。
  • 枚举是有名字的 int 常量，不提供强类型检查。
  • 联合体成员共用内存，大小由最大成员决定。
  • typedef 是别名，能显著简化函数指针声明。
