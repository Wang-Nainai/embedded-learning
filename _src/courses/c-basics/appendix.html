A.1语法与类型速查

主题写法要点
整型signed char / short / int / long / long long宽度用 sizeof 查；跨平台用 <stdint.h>
无符号unsigned int u = 0u;溢出按 2N 回绕，不报警告
浮点float f = 1.0f; double d = 1.0;不要用 == 比较；金额用整数分
字符char c = 'A';'A' 的类型是 int，值为 65（ASCII 平台）
字符串char s[] = "hi";占 3 字节，末尾自动补 '\0'
数组int a[5] = {0};下标 0–4；越界是未定义行为
二维数组int m[3][4];行优先连续存放；传参时列数不能省
指针int *p = &x;*p 取值，p+1 走一个 int
结构体struct S { int a; };用 . 访问，指针用 ->
枚举enum E { A, B = 3 };本质是 int 常量，默认从 0 开始
联合union U { int i; float f; };成员共用内存，大小取最大成员
类型别名typedef unsigned int u32;不产生新类型，只起名字
常量const int N = 10;C 里默认外部链接，放头文件要加 extern

A.2printf / scanf 格式符

类型printfscanf备注
int%d%d最常用
unsigned%u%u不要用 %d
long%ld%ldWindows 上 long 是 4 字节
long long%lld%lld64 位整数
size_t%zu%zu打印 sizeof 必须用这个
double%f / %.2f%lfscanf 读 double 必须加 l
char%c%c读字符不会跳过空白
字符串%s%7sscanf 读字符串必须限宽，否则可能溢出
指针%p—参数要转成 void *
十六进制%x / %08X%x调试寄存器、协议字段常用

A.3常用标准库函数

头文件函数用途 / 注意
stdio.hprintf / fprintf / snprintf格式化输出；snprintf 限制长度，检查返回值是否被截断
stdio.hfgets(buf, n, stdin)安全读一行，保留换行符
stdio.hfopen / fclose / fread / fwrite文件操作；二进制模式记得加 "rb" / "wb"
stdlib.hmalloc / calloc / realloc / free堆管理；检查 NULL，成对释放
stdlib.hstrtol / strtod字符串转数字，能检测非法输入
stdlib.hqsort(b, n, size, cmp)通用排序；比较函数返回负/零/正
stdlib.hexit / abortexit 会刷新缓冲区并执行清理，abort 不会
string.hstrlen / strcmp / strncmp长度与比较；strcmp 相等返回 0
string.hmemcpy / memmove / memset内存块操作；重叠区域必须用 memmove
string.hstrchr / strstr查找字符 / 子串，找不到返回 NULL
ctype.hisdigit / isalpha / toupper参数必须是 unsigned char 或 EOF
math.hsqrt / fabs / pow部分平台需要链接 -lm
limits.hINT_MAX / INT_MIN / CHAR_BIT写可移植的边界检查
stdint.hint32_t / uint8_t / uintptr_t明确位宽，嵌入式必备

A.4常见错误对照表

现象最可能的原因怎么改
段错误 / 访问冲突空指针、越界、释放后使用解引用前判空；检查下标；free 后置空
结果随机变化未初始化变量、越界写破坏栈定义时初始化；开 -Wall；用 ASan
死循环循环变量没更新、无符号倒序、浮点比较检查步进；用整数计数
字符串乱码 / 越界缺 '\0'、缓冲区太小留出终止符空间；用 snprintf
输出被截断snprintf 返回值 ≥ 缓冲区大小检查返回值，扩大缓冲区
链接报未定义引用源文件没参与编译、函数名拼错检查文件清单与拼写
重复定义变量/函数定义写进了头文件头文件只放声明，定义放 .c
结构体大小比预期大对齐填充调整成员顺序，或用 offsetof 检查
浮点比较失败二进制无法精确表示用容差比较，金额用整数

A.5术语表

翻译单元一个 .c 文件经过预处理后的结果，是编译器真正处理的单位。
目标文件汇编产出的机器码文件，含未解析的符号引用。
符号函数名、全局变量名等，链接器按名字把引用和定义接起来。
栈帧一次函数调用在栈上占用的区域，存放参数、局部变量和返回地址。
未定义行为标准不规定结果的行为，编译器可以做任何事，包括“看起来正常”。
实现定义标准允许编译器自行选择，但必须写进文档，例如 char 是否有符号。
数组退化数组名在表达式中转换为指向首元素的指针。
悬空指针指向已释放或已失效内存的指针。
内存泄漏分配的内存失去所有引用，无法再释放。
包含守卫用 #ifndef/#define/#endif 防止头文件被重复展开。
内部链接名字只在当前翻译单元可见，用文件作用域的 static 实现。
序列点表达式求值中保证副作用已完成的点，两个序列点之间不能多次修改同一对象。

参考答案

1. 预处理、编译、汇编、链接。2. 8 字节。3. 0（按 256 取模）。4. 未定义行为。5. 假，-1 被转成无符号最大值。6. 继续执行下一个 case（穿透）。7. 值传递。8. 悬空指针，访问是未定义行为。9. 10 和 3。

10. sizeof、&、用字符串字面量初始化字符数组。11. sizeof(int)，通常 4 字节。12. 前者不能通过 p 改值但可换指向；后者不能换指向但可改值。13. 标准没有为结构体定义 ==，需要逐成员比较。14. 最大成员的大小（并按对齐补齐）。15. 每个包含它的 .c 都会定义一份，链接时重复定义。

16. 没有括号导致优先级错误，且参数可能被多次求值。17. NULL。18. 保持原样，仍然有效，需要自己释放。19. free 后不能再读该节点的成员。20. 终止条件、规模递减、结果组合。

A.7学完之后往哪走

如果你能独立完成第 13 讲的项目，并且能解释其中每一个设计取舍，那么 C 语言的基础已经够用了。接下来有两条路：

路线 A

继续深入 C 与系统

读一读标准库的实现，研究 qsort、printf 是怎么写出来的；学习数据结构（树、哈希表）与算法；尝试用 C 写一个小工具。

路线 B

进入嵌入式方向

从第 2 册开始：寄存器、内存映射、位操作、中断、环形缓冲区。你会发现这一册里的指针、结构体和位运算，全都在那里等着你。

正确做法

不要急着收集更多资料。选一个方向，把第 13 讲的项目扩展出三个新功能（例如分组、导入导出 CSV、模糊搜索），比看完三本书更能提升。
