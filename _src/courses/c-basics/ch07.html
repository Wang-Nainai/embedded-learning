7.1内存是带编号的格子

把内存想成一排格子，每个格子 1 字节，每个格子有一个编号，这个编号就是地址。一个 int 占 4 个格子，它的地址是第一个格子的编号。

指针就是一个变量，里面存的不是普通数值，而是地址。所以指针有两层信息：它自己住在哪（&p），它指向哪（p）。

7.2取地址与解引用

#include int main(void) { int a = 42; int *p = &a; /* p 保存 a 的地址 */ printf("a = %d\n", a); printf("&a = %p\n", (void *)&a); printf("p = %p\n", (void *)p); printf("*p = %d\n", *p); *p = 100; /* 通过指针改写 a */ printf("a = %d\n", a); return 0; } a = 42 &a = 000000B6F4BFFC24 p = 000000B6F4BFFC24 *p = 42 a = 100

地址的具体数值每次运行都可能不同（地址空间布局随机化），所以不要把它写死在代码里，也不要比较两个不相关对象的地址大小。

标准怎么说

%p 要求参数是 void *，所以打印其他类型的指针要先转换。把 int * 直接传给 %p 在可变参数函数里属于类型不匹配，严格说是未定义行为，虽然大多数平台“碰巧能用”。

7.3指针类型为什么重要

既然地址都是一个整数，为什么还要区分 int * 和 char *？因为类型决定了两件事：解引用时读几个字节，以及指针加 1 时前进几个字节。

#include int main(void) { int a[3] = {10, 20, 30}; int *pi = a; char *pc = (char *)a; /* 强制转换：现在按字节看同一块内存 */ printf("pi = %p, pi+1 = %p\n", (void *)pi, (void *)(pi + 1)); printf("pc = %p, pc+1 = %p\n", (void *)pc, (void *)(pc + 1)); printf("*pi = %d\n", *pi); printf("*pc = %d（只读第一个字节）\n", *pc); return 0; } pi = 0000007A1F9FF8E0, pi+1 = 0000007A1F9FF8E4 pc = 0000007A1F9FF8E0, pc+1 = 0000007A1F9FF8E1 *pi = 10 *pc = 10（只读第一个字节）

pi + 1 前进了 4 字节（一个 int），pc + 1 前进了 1 字节。指针算术的单位是“元素”，不是“字节”。

7.4指针运算的合法边界

指针可以加、减整数，也可以两个同类型指针相减。但这一切只在同一个数组（或紧邻末尾的后一个位置）内有定义。

int a[5] = {1, 2, 3, 4, 5}; int *p = a; int *q = a + 5; /* 指向末尾后一个位置：合法，可以比较，不能解引用 */ ptrdiff_t n = q - p; /* 5：两个指针之间隔了 5 个元素 */ int last = *(q - 1); /* 5：合法，q-1 指向 a[4] */ /* 下面这些都没有定义 */ int x = *(a + 5); /* 越界解引用 */ int y = *(a - 1); /* 越界解引用 */ if (a < &some_other_var) /* 不相关对象的地址比较没有意义 */
工程习惯

遍历数组时，用下标 a[i] 通常比裸指针更容易读；只有在需要“滑动窗口”“解析缓冲区”时才用指针。无论哪种写法，都要显式保存长度，并在每次移动后检查边界。

7.5三种“坏指针”

名字怎么来的后果怎么防
空指针int *p = NULL;解引用直接崩溃（多数平台）解引用前判断 p != NULL
野指针int *p; 未初始化指向随机地址，行为不可预测定义时就初始化：int *p = NULL;
悬空指针指向已 free 的内存，或已返回的局部变量读写已释放内存，可能“看起来正常”释放后立刻置 NULL；明确所有权
#include int *make(void) { int *p = malloc(sizeof *p); if (p != NULL) { *p = 7; } return p; /* 合法：堆内存活到 free 为止 */ } int main(void) { int *p = make(); if (p == NULL) { return 1; } free(p); p = NULL; /* 防止后续误用 */ /* free(p); 再来一次是双重释放：未定义行为 */ return 0; }

7.6const 与指针：三种组合

int value = 1; int other = 2; /* 1. 指向常量的指针：不能通过 p 改值，但 p 可以换指向 */ const int *p1 = &value; /* *p1 = 10; 错误 */ p1 = &other; /* 正确 */ /* 2. 常量指针：p 不能换指向，但可以通过 p 改值 */ int *const p2 = &value; *p2 = 10; /* 正确 */ /* p2 = &other; 错误 */ /* 3. 两者都不能改 */ const int *const p3 = &value;

读法：从变量名往右读，const 修饰它左边的东西；如果 const 在最左边，就修饰 * 指向的对象。函数参数里写 const char *s 是在承诺“我不会改你的字符串”，这是 C 里最重要的接口约定之一。

易错

const 只约束“通过这个指针不能改”，不保证对象真的在只读内存里。别人手里可能还有一个非 const 指针指向同一块内存。第 2 册会专门讲 const 与 Flash 的关系，不要提前把它当成“一定放进 ROM”。

参考答案与思路

1. 因为 C 只有值传递，传指针才能让函数拿到调用者的内存地址，从而改写原变量。

2. for (int *p = a; p < a + 6; p++) printf("%d %p\n", *p, (void *)p);。用“尾后指针”做上界是常见写法。

3. 合法，它指向最后一个元素的下一个位置，可以用于比较和作为循环终点，但不能解引用。

4. 第一行第二句编译失败（不能通过指向常量的指针改值）；第二行合法（指针本身是常量，但指向的值可改）。

自测：int a[5]; int *p = a; p + 1 比 p 大多少字节？

指针算术以“所指类型的大小”为单位。int 在主流平台是 4 字节，所以 p+1 前进 4 字节，正好指向 a[1]。若 p 是 char *，才前进 1 字节。

  • 指针存地址；& 取地址，* 顺着地址取对象。

  • 指针算术只在同一数组内有定义，尾后位置可比较但不可解引用。
  • 空指针、野指针、悬空指针是三类最常见的事故源。
