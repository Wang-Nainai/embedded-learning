8.1“数组就是指针”错在哪里

这句话只在表达式求值时部分成立：数组名在大多数表达式里会转换成“指向首元素的指针”，这叫数组退化（array-to-pointer decay）。但数组本身和指针是两种不同的类型。

int a[5] 与 int *p = a 的差别
对比项a（数组）p（指针）
类型int[5]int *
sizeof20（整个数组）8（指针本身）
能否赋值不能，a = p 编译错误可以，p = a 合法
& 的结果int (*)[5]，指向整个数组int **，指向指针变量
存储位置数组对象本身占 20 字节指针变量占 8 字节，另有所指
作为函数参数退化为 int *本来就是 int *

8.2退化的三个例外

数组名在下面三种场合不会退化成指针：

sizeof a　得到整个数组的字节数，而不是指针大小。
&a　得到“指向整个数组”的指针，类型是 int (*)[5]；&a + 1 会跳过整个数组。
用字符串字面量初始化字符数组　char s[] = "abc"; 是按数组规则初始化，不是指针赋值。
#include int main(void) { int a[5] = {1, 2, 3, 4, 5}; int *p = a; printf("sizeof(a) = %zu\n", sizeof(a)); /* 20 */ printf("sizeof(p) = %zu\n", sizeof(p)); /* 8 */ printf("sizeof(*p) = %zu\n", sizeof(*p)); /* 4：一个 int */ printf("a + 1 = %p\n", (void *)(a + 1)); printf("&a + 1 = %p\n", (void *)(&a + 1)); /* 跳过 20 字节 */ printf("差值 = %td 字节\n", (char *)(&a + 1) - (char *)a); return 0; } sizeof(a) = 20 sizeof(p) = 8 sizeof(*p) = 4 a + 1 = 000000C9B7BFF8E4 &a + 1 = 000000C9B7BFF8F4 差值 = 20 字节

a + 1 走一个元素（4 字节），&a + 1 走整个数组（20 字节）。这就是“指向元素的指针”和“指向数组的指针”的区别。

8.3用指针遍历数组

#include int main(void) { int a[6] = {10, 20, 30, 40, 50, 60}; /* 写法 1：下标，最易读 */ for (int i = 0; i < 6; i++) { printf("%d ", a[i]); } printf("\n"); /* 写法 2：指针 + 尾后位置 */ for (int *p = a; p < a + 6; p++) { printf("%d ", *p); } printf("\n"); /* 写法 3：指针 + 计数，适合不知道尾指针的场合 */ int *q = a; for (int n = 0; n < 6; n++) { printf("%d ", q[n]); /* 指针也可以下标，等价于 *(q+n) */ } printf("\n"); return 0; } 10 20 30 40 50 60 10 20 30 40 50 60 10 20 30 40 50 60
标准怎么说

a[i] 的定义就是 *(a + i)。因为加法满足交换律，a[i] 和 i[a] 等价——能编译，但没人这么写。理解这条定义，就能理解为什么下标本质上是指针算术。

8.4数组参数：为什么长度总是丢

#include /* 下面三种写法在函数参数位置上完全等价 */ void f1(int *a, int n); void f2(int a[], int n); void f3(int a[10], int n); /* 这里的 10 会被忽略！ */ void f1(int *a, int n) { printf("函数内 sizeof(a) = %zu\n", sizeof(a)); /* 8，不是 40 */ for (int i = 0; i < n; i++) { a[i] *= 2; /* 改的是原数组 */ } } int main(void) { int data[10] = {1, 2, 3}; f1(data, 10); printf("%d\n", data[0]); /* 2 */ return 0; } 函数内 sizeof(a) = 8 2

所以函数签名里写 int a[10] 只是一种“文档性”写法，编译器根本不检查长度。这也是 C 的数组参数容易越界的原因：长度必须由调用者保证，或者用结构体把数组和长度包在一起。

struct slice { int *data; int len; }; void process(struct slice s) { for (int i = 0; i < s.len; i++) { /* 使用 s.data[i] */ } }

8.5指针数组与数组指针

这两个名字只差一个字，含义完全不同。读法仍然是“从名字往右读”：

/* 指针数组：是一个数组，元素是指针 */ const char *names[3] = {"Alice", "Bob", "Carol"}; /* names[0] 的类型是 const char * */ /* 数组指针：是一个指针，指向“含 3 个 int 的数组” */ int (*row)[3]; int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}}; row = matrix; /* 指向第一行 */ int x = row[1][2]; /* 6 */ /* 函数指针数组：常见于命令表、状态机 */ int (*ops[2])(int, int) = { add, sub };
工程习惯

char *argv[] 就是指针数组，所以 main(int argc, char *argv[]) 里每个 argv[i] 是一个字符串。写复杂声明时，typedef 能救命：typedef int (*binop)(int, int); 之后 binop ops[2]; 一眼就懂。

自测：int a[5]; 下面哪个表达式等于 20？

a + 0 已经退化为指针，得到 8；&a[0] 也是指针，8；只有 sizeof(a) 作用在数组类型上，得到 5×4=20。

本讲小结

  • 数组名在大多数表达式里退化为首元素指针，但它本身不是指针。
  • sizeof(a)、&a、字符串初始化是三个例外。
  • 数组传参必然丢长度，必须另传或封装成结构体。
  • a[i] 等价于 *(a + i)，指针也能用下标。
  • 返回指针前先问：这块内存活到调用者用完吗？
